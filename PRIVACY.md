# Privacy policy

Mistria Tracker is a local desktop application.

- It does not collect analytics, advertising identifiers, account details, or
  game-save contents for transmission.
- It does not send tracker data, discovery history, notes, or companion-log
  events to any remote service.
- It stores its tracker database and preferences locally on the user's device.
- Its optional game companion writes an isolated local event log used only by
  the tracker; it does not modify a Fields of Mistria save file.

Network activity occurs only when the user explicitly requests it, such as
opening a project link or downloading a release through their browser.
